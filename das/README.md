# Usage

* Each file `dasfiles_*.py` reads in the run and lumi information from the csv files and generates a script of DAS queries for the corresponding miniaod files.
* Run the scripts (e.g.): `dasfile_DoubleEG_2016G.sh ../ig/DoubleEG_Run2016G.txt`. This creates an input list of files for the configuration scripts in `/ig` which will generate the event display files.
